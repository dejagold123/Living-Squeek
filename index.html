Your Squeek isn't a stat card. It's a small creature that grows through five stages, and it only grows on work Squeekchain has settled on-chain. You can watch the live wheel too, but live readings never count.

This runs on the Sepolia testnet, so test Squeeks have no monetary value. Living Squeek is an independent project, not an official Squeekchain product. It's prepared for IMD swarm review, with original code, settled-only evolution, and owner actions prepared, never signed, by this page.

    Claim bundle — snack pouch to SQK
    
    
    Enter token IDs separated by commas. They're sorted, de-duplicated and split into batches of up to 32, as the owner-actions guide requires. Each ID's ownerOf is read live first, then the payout is simulated with claimable(0, ids) and a test claim call before the unsigned EIP-5792 bundle appears. If anything fails you get the decoded error, and the page won't retry with different IDs.
    
    
    
    
    
    
    

    
    Merge
    
    
    Pick a survivor and a donor. Checks: you own both (read live), same level, neither at max level, no pending power (pendingRound), and both cooldowns reached. Cooldowns show as bars in completed Squeek blocks (nextMergeHeight minus the current settled height). The merge is simulated before any bundle appears.
    
    
    
      
      
    
    
    
    
      
    
      
    
    
    
    
    
    
    
    
    

    
    Checkpoint — anyone can run one
    
    
    A checkpoint turns settled rounds into rewards for every Squeek, and anyone can run one. This reads checkpointStatus() live, simulates checkpoint() and shows estimated gas before preparing an unsigned bundle. The caller pays the gas and gets nothing back.
